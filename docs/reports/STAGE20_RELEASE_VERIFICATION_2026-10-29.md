- Внешних запросов 0, JS-диалогов (XSS) 0, горизонтального переполнения 0.
- Найдено и исправлено:
  - **вход не работал в браузере**: `Referrer-Policy: no-referrer` → Chrome шлёт `Origin: null` в POST формы входа. Теперь `same-origin`; `Origin: null` по-прежнему отклоняется.
  - **таблицы на 390 px**: прокрутка вбок, скрытые причины. Теперь карточки с подписями (CSS).
- Cookie `Secure` принимается Chrome на `http://127.0.0.1`.
- Скриншоты оставлены локально (не в репозитории).

## 4. PDF (PDFium)

Синтетические документы: CV, письмо, 3-страничный CV, документ с длинными заголовками, словами и URL.

- Все страницы A4 (595,28 × 841,89 pt), весь текст внутри полей 62 pt, ничего не обрезано, пустых страниц нет.
- Умлауты, ß, €, „“, тире — верно. `Łódź` отклоняется (`UnrenderableTextError`), а не заменяется.
- Повторный экспорт — те же SHA-256; дат и ID в файле нет; извлечённый текст совпадает с исходными блоками.
- Настоящий `presubmit_check.py`: без `--bind` — `NEEDS_OPERATOR` (exit 3), после `--bind` — `READY` (exit 0). Подменённый, изменённый PDF или испорченный источник не привязываются.
- Ограничение: в письме нет адреса получателя и даты (DIN 5008) — этих данных нет в подтверждённой identity, генератор их не выдумывает.
